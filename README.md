# 🎬 CinePhile

CinePhile is a dynamic web application for movie enthusiasts, featuring a fully integrated Firebase dashboard for real-time data handling and task configuration.

## ✨ Key Features
* **Real-time Sync:** Live data management and storage powered by Firebase.
* **Interactive Dashboard:** A clean, user-friendly interface to configure and track tasks.
* **Responsive Design:** Optimized for seamless use across all devices.

## 💻 Tech Stack
* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Firebase (Firestore / Realtime Database)

## 🚀 Quick Start

1. Clone the repo.
2. Setup Firebase: Create a Firebase project and add your web app configuration keys to the project directory.
3. Run: Open index.html in your browser (or start your local dev server) to view the dashboard.
